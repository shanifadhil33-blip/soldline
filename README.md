# Soldline

For marketing agencies of 10 to 80 people who sell in HubSpot and deliver in ClickUp. Every sold deliverable gets an owner, a deadline and an approval.

Status: early setup

Use Node 22 and pnpm. Run `pnpm install`, then `pnpm dev`. Run `pnpm gate` to check the app. Browser checks live in the separate e2e package.

Stack: Next.js 16, TypeScript, Tailwind 4, Drizzle, Neon, Auth.js, Vitest, PGlite, Playwright and MSW.
