# P4 integrations

Typed provider adapters use a shared request layer. Each request loads the encrypted credential server side, checks the provider connection, consumes its persistent bucket and records a fresh request id. Retry After seconds and HTTP dates and ClickUp reset epoch seconds permit one retry inside the call. Missing or invalid reset headers produce RateLimited immediately. Network failures, invalid success payloads and server failures produce Retryable. Authentication failures commit the reconnect status and audit record before throwing NeedsReconnect.

Connections accepts an internal privileged worker driver and an active member identity. It creates no database connection itself and is not exposed through routes. Each operation commits separately so an error in a caller transaction cannot erase provider health. Administrative credential changes require an admin role. Saving a credential clears the reconnect status. Resume only changes a deliberately paused connection. The app role retains its existing read policies and receives no new table write privileges.

HubSpot buckets use the external account id. ClickUp buckets use a SHA 256 fingerprint of the token. Both refill continuously to 100 tokens at the configured interval. Shared account or token credentials across workspaces share a bucket. A database row lock serializes consumption. Exhausted local buckets return a retry time without making an HTTP request. Mail has no guessed provider rate limit.

Client methods validate response shapes and keep provider bodies and thrown transport details out of public errors and audit data. Tests also serialize every error property to check token safety. Successful calls update last_ok_at. Demo outage and revoked fault rows decrement only for demo workspaces. Real workspaces ignore the same rows without consuming them.

The example environment file remains untouched under the shared boundary. MAIL_API_BASE and the other settings are documented in STATE.md. Unknown HubSpot endpoints deliberately require explicit configuration. Mail endpoints and seed contracts remain UNVERIFIED as listed in STATE.md. No live API, real database, sign in, global installation, seed entry, commit or push was used.
