# P15a Harbor approval

The seeded Harbor provision approval is real work. `seedWaitingItems` builds it with `provisionPayload` and `exactApprovalFields`, the same hash and role fields the approvals store writes. Its input is the stored scope version, which the live comparison accepts. The client email approval is unchanged and stays on the sample inbox.

## Files

- `src/server/approvals/model.ts` shares the exact pending approval fields.
- `src/server/demo/seed.ts` stores the eight task plan and the executable provision approval. Ravi has ClickUp user 42.
- `src/server/demo/safety.ts` refuses the protected deal and any sample id.
- `src/server/executor/worker.ts` simulates a provider with no token, and allocates a sandbox deal before a live HubSpot write.
- `src/server/executor/store.ts` records the sandbox deal for cleanup and labels a simulated result.
- `src/components/run-detail.tsx` shows that label on the run.
- `e2e/fixtures/core.ts` keeps the seeded provision approval and still prepares the stale approval.
- `tests/p15a-demo.test.ts` covers the seed, the simulation, the live sandbox write, the refusal, and the retry.
