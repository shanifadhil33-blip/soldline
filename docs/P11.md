## Decisions

The home uses the exact requested English headline, subline, buttons and section titles. Its quiet handover diagram is limited to the public home. Warm paper surfaces, muted teal actions, camel borders and existing fonts serve both languages. There are no new dependencies, gradients, sparkle icons, stock pictures or generated pictures.

The proxy accepts en or ar through the lang query, remembers that choice in a cookie and supplies a validated request header. Root html sets lang and dir before rendering. Language links preserve the current page. loadMessages returns the same typed message shape in either language. formatNumber explicitly selects Western digits and applies asciiDigits, which also handles both common Arabic digit ranges. Arabic copy was written by hand. Soldline, HubSpot, ClickUp and Next.js retain their names. Agent has not been renamed or translated.

The app layout resolves the existing session, redirects missing members to the existing sign in page and reads the workspace name with the existing member transaction and row security. It adds no data mutations. Demo roles and names come from the existing six persona ids. Tests compare the browser safe persona list with the server seed so they cannot silently diverge. No personas were added.

Staff get the eight requested laptop links and Today, Runs, Queue and More on phones. Queue opens Recovery. More opens the remaining staff destinations. Client reviewers get Home and Inputs on both screen sizes. The frame chooses the variant from the authenticated member roles. All destination pages are explicit placeholders and expose no business records. Recovery badges accept recoveryCount and render only for a positive value. The default is 0, including the browser smoke.

The header includes the workspace name, demo persona selector, Sample data badge and Reset demo. A native modal dialog requires confirmation before the existing demo start API is called. There is no reset API in this repo. Confirming therefore reopens the existing demo start flow for the current persona and retains the sandbox and existing sample work, as the dialog explains. Cancelling makes no request. This follows the allowed existing API fallback and does not invent a backend reset operation.

The demo picker announces creating, ready and error states, offers Retry after failure and opens the correct staff or client home only after the existing start API confirms success. Server error bodies never become visible copy. Existing Auth.js pages and Memory remain at their original URLs.

## Browser fixtures

The explicit SOLDLINE_SHELL_FIXTURES=1 webpack build replaces only the database runtime module with e2e/fixtures/runtime.ts. The fixture creates a local PGlite database, applies the existing migrations and runs the existing owner services and member role transactions. Demo starts therefore exercise the actual existing API, signed cookies, sandbox seed and session checks. MSW rejects every external HTTP request from that fixture. Only loopback requests may pass through. No remote database or provider is needed.

The browser setup refuses a build without the compiled local fixture guard. It cannot silently run these demos against a standard production build. The replacement is confined to the explicit fixture webpack build. A normal pnpm gate uses the standard production runtime. The final gate rebuilds the normal app after browser verification. Test signing values are disposable local fixture values supplied by Playwright, never read from an environment file.

From the repo root, Bilal can run the browser suite with the existing local tools:

```sh
export PATH=/home/box/.local/node22/bin:$PATH
node --version
SOLDLINE_SHELL_FIXTURES=1 pnpm build --webpack
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/google-chrome pnpm --dir e2e test
pnpm gate
```

Node must print v22 before the pnpm commands. The browser path above is the existing Chrome executable used in this sandbox. If Bilal already has Playwright Chromium, he can omit PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH. No browser or package was installed for P11. Browser tests remain separate from the gate.
