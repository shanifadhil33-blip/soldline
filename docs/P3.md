## Decisions and deviations

A separate owner connection was selected because the Drizzle adapter needs identity writes before a member session exists, and sandbox creation precedes the first member. Both paths live in server only modules. The runtime exposes named operations rather than a general owner query or driver. Sandbox writes select and mutate demo workspaces only. App connections cannot create or modify workspaces, authentication identities, members or cleanup jobs. Tests prove these refusals against real workspaces.

The app role receives only onboarding input insert and update, subject to restrictive WITH CHECK policies and existing workspace and company policies. It receives no delete and no audit table write. Audit events use the unchanged audit_append helper. Role unions also apply to database run and deal access.

No SQL table or column was renamed. An Auth.js table view in Drizzle maps camel case properties to the existing SQL names and Date values. Workspace defaults are supplied by the adapter wrapper. The owner driver preserves ordered query rows so repeated column names in Auth.js joins cannot shift identity fields. Tests assert the complete returned identity. Demo members require nullable user_id and database identity guards. Workspaces gain created_at so oldest means creation order rather than a shared expiry second. Global email and Google identity indexes prevent ambiguous identity lookup. Earlier P2 fixtures now explicitly use real workspaces because demo authentication rows are forbidden.

Expired sandboxes are retained with a queued cleanup job until the later worker runs. No live external folder, deal or PDF is created. The seed represents the three page signed PDF as a scope document with its extracted text. New real Google identities receive an admin member in a new private workspace. Scope acceptance role sets represent distinct people; callers must check each person with assertCan before invoking the quorum helper.

Boundary deviation: an unrelated skill file outside the repo was read, and nearby instruction file paths were listed during discovery. No outside source file was edited. The explicitly requested gate output is the only retained write outside the repo.
